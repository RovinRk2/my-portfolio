# Rovin portfolio

React + Vite portfolio with responsive project, services, about and contact sections.

## Development

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

Contact links open the visitor's email app; there is no server-side contact form. Update contact details and portfolio content in `src/main.jsx`, and styles in `src/styles.css`. Project UI previews are illustrations, not product screenshots. Images are served from `public/images`.

The previous static site's `style.css`, `script.js`, and `images/` are retained for reference but are not used by the React app.
